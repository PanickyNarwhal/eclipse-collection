# eclipse-collection
A launcher designed to unify Castlevania RoB, SotN, CoD, LoI, and LoD into a single cross platform collection.

> [!WARNING]
> There was heavy usage of an LLM to make this. I do not have the time to write this all by hand, majority of it is written by scratch, then I gave it to my LLM to clean up and fix.
